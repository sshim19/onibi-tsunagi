# 鬼火つなぎ

夜の境内を漂う鬼火を、同じ色でなぞってつなぐゲームです。同じ日は、だれが遊んでも同じ並びから始まります。

## 遊び方

1. 「つなぐ」を押して始めます。制限時間は60秒です。
2. 同じ色の鬼火を指（またはマウス）で3つ以上たどってはなすと、消えて点になります。
3. 違う色に触れると、つながりは途切れます。空いているところを通っても、つながりはそのままです。
4. 7つ以上つなぐと、まわりの鬼火もまとめて消せます。
5. 短いあいだに続けて消すと、コンボで得点が増えます。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
